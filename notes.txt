To save your current package list: Run this command in your terminal while your virtual environment is active:
pip freeze > requirements.txt

To install everything from scratch: If you ever clone this repository onto a new machine, you just create a fresh .venv, activate it, and run:
pip install -r requirements.txt

To interact with the file system manager
pip3 install pynput


-----
On the Terminal be sure to run
$env:PYTHONPATH="$env:PYTHONPATH;."

on the .venv folder, look for the Activate.ps1 and add the following line at the bottom
$env:PYTHONPATH = "$env:PYTHONPATH;$PSScriptRoot\.."


pip3 install pytest
pip3 install pytest-ordering

To run all TC in a folder, you can use the following command in your terminal:
pytest -v -s PytestFW/

To run the tests in this file, you can use the following command in your terminal:
pytest -v -s PytestFW/test_case_demo1.py

To run a particular test_method, you can use the following command:
pytest -v -s PytestFW/test_case_demo1.py::test_methodA
pytest -v -s PytestFW/test_case_demo1.py -k test_methodB

To run using parameters
pytest -v -s PytestFW/test_run_order_demo.py --browser firefox --osType iOS


To generate html basic reports
pip3 install pytest-html

pytest -v -s PytestFW/test_class_demo.py --html=PytestFW/test_class_demo_report.html
